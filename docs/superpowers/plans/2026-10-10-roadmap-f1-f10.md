# Spark roadmap F1–F10 Implementation Plan

> **For agentic workers:** executed inline with superpowers:executing-plans, test-first per superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the design doc's unbuilt features (F1, F2's agents and merge gate, F3, F4, F5, F7, F8, F9, F10) into the Spark mod and launcher, and confirm F6.

**Architecture:** Each feature's logic is a pure module in `plugin/hooks/*.ts` (tested with `claude-code/testing`) or `src/*.js` (tested with `node:test`). `register.tsx` wires them to the mod API: `tool.check` for the command gate, `tool.call` for pruning, the halt's denies, design-doc capture and reviewer verdicts, and `classic.Stop` with `{ block }` for the test gate. Skills and agents are plain plugin files.

**Tech Stack:** Claude Code mod API (TypeScript, early access), Node 24 ESM, `node:test`, `claude plugin test`, git.

**Spec:** `docs/design/2026-10-09--spark--design.md`

## Global Constraints

- Windows only; every shell rule covers Bash and PowerShell.
- The gate "never returns `allow`: everything not denied still goes through CC's normal permissions."
- "Per-repo settings live here [`%APPDATA%\spark\config.json`], keyed by absolute path, and are **never read from the repo**."
- Messages Spark sends Claude start with `✦`.
- "The MISP gains lines about each one only when it exists."
- No new runtime dependency unless the spec names it (F3 names web-tree-sitter).
- `npm run check` after any `.ts` change; `cd app && npm test` after any change to code the app stages.

## Review Focus

1. Quoted separators: `git commit -m "fix; rm -rf /"` or `echo "a && b"` must not split into commands or trigger a rule.
2. A test command that hangs, or a repo with no test command: the Stop gate times out at 300 s or stays off; it never blocks forever or loops.
3. While halted, edits under `docs/postmortems/` still go through, and `/spark-unhalt` is refused until a post-mortem newer than the halt exists.
4. Pruning touches only successful Bash/PowerShell output over 200 lines; the saved full copy exists at the path the note names.
5. A subagent's calls (`agentId` set) still pass the gate; the test gate runs on the main loop only.
